to 720 px. Sources (Wikimedia Commons):

Used only by `FindMyCrewTests`; not bundled with the app.

`NoImageInput.mlpackage` is a 4 KB Core ML program generated for the tests (array input, no image input), used to
check that the custom-model import rejects models that break the I/O contract.
Its manifest requires `Data/com.apple.CoreML/weights` even though this model uses
only inline constants. The `.gitkeep` preserves that empty directory in clean
checkouts; without it Core ML fails to open the package before contract validation.

`Contracts/*.mlmodel` are tiny constant-output neural networks generated by
`scripts/models/build_contract_fixtures.py` with `.venv-models/bin/python`. They
exercise fixed and flexible output shapes, required inputs, image dimensions,
alignment metadata, threshold bounds, and unusable embeddings. They contain no
third-party weights or images.
